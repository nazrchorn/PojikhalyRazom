# Налаштування Firebase правил

## Cloud Storage Rules

Cloud Storage правила знаходяться у файлі `storage.rules`. 

Ці правила дозволяють:
- Всім користувачам **читати** фото профілю та поїздок
- Користувачам **завантажувати** тільки свої власні фото в папку `profile_photos/{userId}`
- Користувачам **видаляти** свої власні фото

## Firestore Rules

Firestore правила знаходяться у файлі `firestore.rules`.

Ці правила забезпечують:
- Публічний доступ до читання даних користувачів
- Користувачи можуть редагувати тільки свої власні документи
- Поїздки можуть читати всі, але редагувати тільки водій та пасажири
- Повідомлення читають тільки відправник і одержувач
- Відгуки можуть створювання всім залогіненим користувачам

## Розгортання правил

Щоб розгорнути правила на Firebase:

```bash
firebase deploy --only firestore:rules,storage
```

## Отладження помилок завантаження фото

Якщо виникає помилка при завантаженні фото:

1. **Перевірте Cloud Storage правила**: Заходьте в Firebase Console → Storage → "Rules" 
   та перевірте, що користувач авторизований (перевіром `request.auth.uid == userId`)

2. **Перевірте розмір файлу**: Максимум 5MB встановлений у коді

3. **Перевірте доступ користувача**: Переконайтесь, що користувач авторизований в нашій системі

4. **Логи**: Перевіряйте лог `debugPrint` в Dart коді для детальної інформації про помилку

## Структура завантаження

Фото завантажуються за такою структурою:
- Профільні фото: `profile_photos/{userId}/avatar.jpg`
- Фото поїздок: `trip_photos/{tripId}/{photoId}.jpg`
