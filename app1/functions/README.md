# Cloud Functions (Chat Push)

This folder contains Firebase Cloud Functions for chat push notifications.

## Functions

- `onNewMessagePush`: Firestore trigger on `messages/{messageId}`. Sends push to `receiverId` using `users/{uid}.fcmToken`.
- `sendTestPush`: Callable function for quick verification (sends push to the signed-in caller).

## Required Firestore fields

### `messages/{messageId}`

- `senderId: string`
- `receiverId: string`
- `text: string`

### `users/{uid}`

- `fcmToken: string` (written by Flutter app on login/init)

## What the cloud code does
- onNewMessagePush:
* Trigger: messages/{messageId} created
* Reads senderId, receiverId, text
* Loads receiver fcmToken from users/{uid}
* Sends FCM push notification
* Deletes invalid token automatically if FCM reports it invalid
- sendTestPush:
* Callable function for quick testing
* Sends push to currently signed-in user’s own token
